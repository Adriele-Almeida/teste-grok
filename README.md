# Pauta

Calendário simples de conteúdo. O cliente vê a arte, a legenda e o dia da postagem, e pode aprovar, pedir ajuste ou reprovar.

## Uso

- **Nome do cliente** — personaliza esta cópia
- **Novo post** — arte, legenda, data e hora
- **Ano, mês e semana** — do calendário inteiro até o dia
- **Aprovar, pedir ajuste, reprovar** — o comentário fica no histórico

Cada cliente pode ter a própria cópia deste repositório.
